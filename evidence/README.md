# evidence

What lands here, once the runs are real:

- a saved capability artifact from a successful discovery run,
- the structured log from that discovery run,
- the log from a deterministic replay of the same artifact,
- at least one replay that hits an exceptional state (a bad input or a not-found result), to show
  how the condition is detected, classified and reported.

Everything here is generated by an actual run against the target application. Nothing in this
folder is written by hand.

No real credentials and no real PII appear in any of it. The target application is a local
stand-in and its data is fabricated.
